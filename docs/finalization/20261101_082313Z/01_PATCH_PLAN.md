### 1. Item A: TFIM Symmetry (P02)
- **Anchor:** `paper/main.tex:90-92`
- **Current Text:**
```latex
For ground states of Eq.~\eqref{eq:tfim}, the $\mathbb{Z}_2$ spin-flip parity symmetry generated by $P = \prod_{i=1}^n X_i$ enforces $\langle Z_i \rangle = \langle Y_i \rangle = 0$ and $\langle X_i Z_j \rangle = \langle Y_i Z_j \rangle = 0$. Consequently, the 1-qubit reduced density matrix at site $i$ is exactly $\rho_i = \frac{1}{2}(I + \langle X_i \rangle X_i)$.
```
- **Proposed Text:**
```latex
For real, parity-definite ground states of Eq.~\eqref{eq:tfim}, symmetry restricts the non-vanishing Pauli expectations. Specifically, $\mathbb{Z}_2$ spin-flip parity generated by $P = \prod_{i=1}^n X_i$ anticommutes with $Y$ and $Z$, eliminating eight components on any pair $(i, j)$: the single-site expectations $Y_i, Z_i, Y_j, Z_j$, and the two-site cross-terms $X_i Y_j, X_i Z_j, Y_i X_j, Z_i X_j$. Furthermore, because the Hamiltonian is real symmetric in the standard computational basis ($H^* = H$), non-degenerate ground states are real ($K|\psi_0\rangle = |\psi_0\rangle$, where $K$ denotes standard complex conjugation). Because $K$ negates $Y$ while preserving $X$ and $Z$, reality eliminates the two remaining cross-terms $Y_i Z_j$ and $Z_i Y_j$. (Note that $K$ represents basis-dependent complex conjugation, distinct from physical spin-1/2 time reversal $\mathcal{T} = (\prod_k i Y_k) K$.) Consequently, only identity, local $X_i$, and the diagonal correlators $X_i X_j, Y_i Y_j, Z_i Z_j$ can remain non-zero. The 1-qubit reduced density matrix at site $i$ is therefore exactly $\rho_i = \frac{1}{2}(I + \langle X_i \rangle X_i)$.
```
- **Evidence:** Analytical Pauli algebra; `docs/stage5/audit_20261101/REPORT.md` Section 7 and Item IT-16.

### 2. Item B: Representation Identity (P03)
- **Anchor:** `paper/main.tex:103`
- **Current Text:**

- **Proposed Text:**
```latex
Similarly, the 2-body nearest-neighbor projected kernel PQK-2nn evaluates 2-qubit reduced density matrices over graph edges $\mathcal{E}$. For a 1D open chain ($n=8$, $|\mathcal{E}|=7$ edges), the edge-stacked feature map $f_{E_2}(\psi) \in \mathbb{R}^{35}$ stacks the 5 non-vanishing Pauli expectations $(X_i, X_{i+1}, X_i X_{i+1}, Y_i Y_{i+1}, Z_i Z_{i+1})$ across all nearest-neighbor edges. The squared Frobenius distance between 2-qubit reduced states satisfies $\|\rho_{ij}(\psi) - \rho_{ij}(\phi)\|_F^2 = \frac{1}{4}\sum_{O} (\langle O \rangle_\psi - \langle O \rangle_\phi)^2$. For an open chain, interior sites $i \in \{1,\dots,n-2\}$ belong to two adjacent edges, while boundary sites belong to one. Repeating $\langle X_i \rangle$ in each incident edge's coordinate representation algebraically weights site $i$ by its graph degree $\text{deg}_i$, providing the exact $\sqrt{\text{deg}_i} = \sqrt{2}$ factor required in Euclidean distance to match Frobenius edge summation: $D^2_{\mathrm{RDM}}(\psi, \phi) = \sum_{(i,j) \in \mathcal{E}} \|\rho_{ij}(\psi) - \rho_{ij}(\phi)\|_F^2 = \frac{1}{4} \|f_{E_2}(\psi) - f_{E_2}(\phi)\|_2^2$. Global bandwidth normalization (e.g., dividing by $4n=32$) remains mathematically separate from coordinate multiplicity weights. Evaluating this raw squared distance across saved TFIM reference states confirms that $|D^2_{\mathrm{RDM}} - 0.25 D^2_{E_2}| \le 5.55 \times 10^{-17}$ across 10 documented state pairs (and $\le 1.33 \times 10^{-15}$ across all 45 pairs), whereas unweighted coordinates produce a substantial residual ($0.5614$). Divergence observed in heuristic sweeps between PQK-2nn and E2 (raw) is an artifact of differing grid normalizers ($c/32$ for $4n$ vs $c/35$ for $5(n-1)=35$) rather than distinct physical representation geometry~\cite{Canatar2023bandwidth}.
```

### 4. Item D: Deployed Budget Accounting (P08)
- **Anchor:** `paper/main.tex:188`
- **Proposed Text (P08):**
```latex
To evaluate models under identical total measurement budgets $B_{\mathrm{tot}}$, we account for state preparations and readout settings across the full evaluation pool ($N_{\mathrm{tot}} = N_{\mathrm{tr}} + N_{\mathrm{te}} = 240$ states). For feature models (PQK-2nn), measuring all single-site and nearest-neighbor observables in a given Pauli basis ($X, Y,$ or $Z$) requires only a single joint projective readout per state, as commuting observables are simultaneously evaluated from the shared bitstring statistics. Thus, measuring all features across all 240 states requires $N_{\mathrm{settings}} = 3 \cdot N_{\mathrm{tot}} = 720$ measurement settings, allocating $S_{\mathrm{feat}} = \lfloor B_{\mathrm{tot}} / 720 \rfloor$ circuit shots per setting. In contrast, fidelity kernels require independent swap tests for each state pair. In deployed evaluation mode, the kernel evaluates $\binom{N_{\mathrm{tr}}}{2} = 780$ training pairs and $N_{\mathrm{tr}} N_{\mathrm{te}} = 8{,}000$ test-train query pairs, yielding $N_{\mathrm{pairs}} = 8{,}780$ pairs and allocating $S_{\mathrm{swap}} = \lfloor B_{\mathrm{tot}} / 8{,}780 \rfloor$ shots per entry.
```
- **Evidence:** `scripts/stage2_equal_budget.py:112-117`; `paper/tables/tab_equal_budget.tex`.
